# Summer League Funhouse shell

This is a disconnected beta shell for summer-league coverage.

It is not canonical Playbook source data, not regular-season automation, and not Ghost publishing code.

Use it to prototype:

- fake-serious scoreboard copy
- real roster/contract tracking
- actual game and box-score links

- summer-only gags that should not leak into the regular-season product
